# 🩺 Dialysis Taskboard

A role-based task management system designed for healthcare workflows. This application helps coordinate tasks among nurses, dieticians, and social workers for patient care.

---

## 🚀 Features

* 👩‍⚕️ Role-based task assignment (Nurse, Dietician, Social Worker)
* 📋 Task status tracking (To-do, In Progress, Done)
* 🧑‍🤝‍🧑 Patient-wise task organization
* 📅 Due date support
* ⚡ Fast UI with React + Vite

---

## 🛠️ Tech Stack

* **Frontend:** React + TypeScript
* **Build Tool:** Vite
* **Styling:** CSS
* **Mock API:** MSW (Mock Service Worker)
